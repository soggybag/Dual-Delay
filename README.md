# Dual Delay (working name)

Two PT2399 delay lines whose repeats can feed themselves, each other, or a blend of both. Idea stage (2026-10-25).

- **Idea and design plan:** [docs/Ideas.md](docs/Ideas.md)
- **Sibling project:** `../Loop Echo/` (single PT2399 + effects loop in the feedback). The delay block, limiter, LFO and mixer are reused from it (its PT2399 network comes from the user's Small Time, 2022).

- **Schematic:** [docs/DualDelay_schematic.pdf](docs/DualDelay_schematic.pdf), generated by `scripts/build_dualdelay.py` (`DualDelay.kicad_sch`). ERC 0. Rev 1.0.
- **Board:** `DualDelay.kicad_pcb`, from `scripts/buildpcb_dualdelay.py` (don't re-run it after editing the board in KiCad).

**Panel (1590BB landscape):** TIME 1, TIME 2, MIX over FB 1, TWIST, FB 2; SERIES toggle; status LED; one footswitch. Internal trims: RATE, DEPTH (LFO on line 2), FB MAX 1 / 2.

**Status:** **v1.0 SMD (2026-10-25)**, to be ordered as a prototype together with Loop Echo (not breadboarded). ERC 0. JLC basic parts except the two PT2399s. One AMS1117-5.0 per PT2399, kept apart on the board; FB MAX trims. Board `DualDelay.kicad_pcb`: 1590BB landscape, 100 × 83.5 mm, jacks on the top wall (OUT · DC · IN). Details: the v1.0 section of [docs/Ideas.md](docs/Ideas.md). **Fab files (2026-10-25):** `production/` (gitignored): `DualDelay.zip` (Gerbers + drill, slots included), `bom.csv` + `positions.csv` (105 SMD placements, top side, 28 lines, all LCSC), `DualDelay_hand_solder.csv`. In JLC's preview check U1 / U2 (PT2399) and U7 / U8 (SOT-223) rotation; the op-amps carry FT Rotation Offset 270. Drilling: [enclosure/README.md](enclosure/README.md). Board DRC: 0 errors / 0 unconnected, parity clean, silk warnings only (silk pass to do, then regenerate the Gerbers). v0.2 breadboard schematic and its [Breadboard Plan](docs/Breadboard%20Plan.md) kept for reference (`scripts/build_dualdelay_v0.2.py`).
